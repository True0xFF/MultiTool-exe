# MultiTool v0.8.0

Консольный мультитул системного администратора Windows. Статический
исполняемый файл без зависимостей, Windows 7–11, собран под Go 1.20.14.
Две разрядности:

- `multitool-x64.exe` — для 64-битной Windows;
- `multitool-x86.exe` — для 32-битной Windows (и для переноса почты в
  32-битный Outlook — разрядность должна совпадать).

## Что нового в 0.8.0

- Перенос почты переработан. Письма теперь переносятся приёмом PostItem
  (IPM.Post → IPM.Note): они больше НЕ остаются неотправленными черновиками,
  даты получения/отправки сохраняются, письмо кладётся сразу в нужную папку.
- Импорт писем возобновляемый: прервали — запустите снова, уже перенесённые
  письма пропускаются (файл состояния в папке экспорта).
- Импорт контактов из LDIF (`.ldif`) с автоопределением кодировки
  (UTF-8/CP1251/KOI8-R) — без потери кириллицы.
- Проверка разрядности Outlook: программа предупредит, какой exe запускать,
  если разрядность не совпадает.
- Пункт «Как выгрузить почту из The Bat!» показывает точные шаги экспорта.

## Ранее

- 0.7.0 — пункт «Права и учётки»: состав локальных групп, выдача/снятие прав
  администратора штатными средствами, при необходимости от имени другого
  пользователя.
- 0.6.0 — драйверы: цветной статус, фильтры, управление устройствами и
  установка драйверов из папки.

Полная история — в `CHANGELOG.md` исходного репозитория.

## Подпись

Оба файла подписаны самоподписанным сертификатом (Authenticode SHA-256),
сертификат для доверия — `multitool-codesign.crt`. Контрольные суммы —
в `SHA256SUMS.txt`.
