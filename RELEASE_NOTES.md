# MultiTool v0.6.0

Консольный мультитул системного администратора Windows. Статический
исполняемый файл без зависимостей, Windows 7–11, собран под Go 1.20.14.
Две разрядности:

- `multitool-x64.exe` — для 64-битной Windows;
- `multitool-x86.exe` — для 32-битной Windows (и для переноса почты в
  32-битный Outlook — разрядность должна совпадать).

## Что нового в 0.6.0

- Драйверы: цветной статус каждого устройства (работает / откл. / устар. /
  проблема / ошибка) с текстовой пометкой — смысл виден и без цвета; легенда
  над списком.
- Драйверы: фильтры списка — все, принтеры и сканеры, проблемные, отключённые,
  сторонние, без подписи; одинаковые драйверы сворачиваются в одну строку.
- Драйверы: управление — включить/отключить устройство и установка драйверов
  из папки (поиск .inf, pnputil с откатом на синтаксис Windows 7).

Полная история — в `CHANGELOG.md` исходного репозитория.

## Подпись

Оба файла подписаны самоподписанным сертификатом (Authenticode SHA-256),
сертификат для доверия — `multitool-codesign.crt`. Контрольные суммы —
в `SHA256SUMS.txt`.
