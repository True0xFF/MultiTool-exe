# MultiTool v0.9.0

Консольный мультитул системного администратора Windows. Статический
исполняемый файл без зависимостей, Windows 7–11, собран под Go 1.20.14.
Две разрядности:

- `multitool-x64.exe` — для 64-битной Windows;
- `multitool-x86.exe` — для 32-битной Windows (и для переноса почты в
  32-битный Outlook — разрядность должна совпадать).

## Что нового в 0.9.0

- Журнал `tool.log` теперь в формате JSON (по событию на строку) с ротацией по
  размеру (~10 МБ, до 5 копий) — удобно разбирать и прикладывать к заявке.
- «Просмотр журнала» показывает его в читаемом виде, открывать JSON вручную не
  нужно.
- При старте в журнал записываются версия, ОС, разрядность, разрядность
  Outlook, объём и свободная память, свободное место на диске.
- Пароли и секреты в журнал по-прежнему не попадают.

## Ранее

- 0.8.0 — перенос почты: письма переносятся приёмом PostItem (не остаются
  черновиками, даты сохраняются), возобновляемый импорт, контакты из LDIF,
  проверка разрядности Outlook.
- 0.7.0 — «Права и учётки»: состав локальных групп, выдача/снятие прав
  администратора, при необходимости от имени другого пользователя.
- 0.6.0 — драйверы: цветной статус, фильтры, управление устройствами.

Полная история — в `CHANGELOG.md` исходного репозитория.

## Подпись

Оба файла подписаны самоподписанным сертификатом (Authenticode SHA-256),
сертификат для доверия — `multitool-codesign.crt`. Контрольные суммы —
в `SHA256SUMS.txt`.
