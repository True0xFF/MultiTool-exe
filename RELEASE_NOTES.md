# MultiTool v0.7.0

Консольный мультитул системного администратора Windows. Статический
исполняемый файл без зависимостей, Windows 7–11, собран под Go 1.20.14.
Две разрядности:

- `multitool-x64.exe` — для 64-битной Windows;
- `multitool-x86.exe` — для 32-битной Windows (и для переноса почты в
  32-битный Outlook — разрядность должна совпадать).

## Что нового в 0.7.0

- Новый пункт меню 11 «Права и учётки»: текущие права пользователя (имя, SID,
  повышение UAC, членство в «Администраторах», домен/рабочая группа) и состав
  локальных групп «Администраторы» и «Пользователи» по well-known SID
  (независимо от языка Windows).
- Добавление/удаление пользователя из «Администраторов» штатными средствами,
  при необходимости — от имени другого пользователя (доменного админа). Пароль
  держится только в памяти и в журнал не пишется.
- Пункты меню после «Прав доступа (ACL)» сдвинулись на один: почта — 12,
  отчёт — 13, журнал — 14.

## Ранее (0.6.0)

- Драйверы: цветной статус устройств с текстовой пометкой, фильтры (принтеры/
  сканеры, проблемные, отключённые, сторонние, без подписи), управление
  (включить/отключить устройство, установка драйверов из папки).

Полная история — в `CHANGELOG.md` исходного репозитория.

## Подпись

Оба файла подписаны самоподписанным сертификатом (Authenticode SHA-256),
сертификат для доверия — `multitool-codesign.crt`. Контрольные суммы —
в `SHA256SUMS.txt`.
