# MultiTool v0.1.0

Консольный мультитул системного администратора Windows. Один статический
`multitool.exe` (amd64), Windows 7–11, собран под Go 1.20.14.

- запуск с запросом прав администратора (UAC);
- 13 функций: сведения о системе, оборудование, драйверы, сканирование сети,
  DNS, сетевая диагностика, принтеры, общие папки, открытые файлы и сессии,
  права NTFS, перенос The Bat! → Outlook, сводный отчёт, журнал;
- подписан самоподписанным сертификатом (Authenticode SHA-256), сертификат
  для доверия — `multitool-codesign.crt`.
