# MultiTool

Одна программа — весь первый час у чужого компьютера.

Я собрал её для себя: выезжаешь к технике, где стоит то Seven, то свежая
одиннадцатая, половина «современных» утилит отказывается запускаться на
старом ядре, а под рукой нужен и просмотр железа, и очередь печати, и права
на папку. Таскать десяток exe надоело — пусть будет один.

Поэтому здесь нет установщика, нет .NET, нет «скачайте ещё вот это».
Один файл `multitool.exe` кладётся на флешку и работает хоть на голой
Windows 7 без интернета.

---

## Что внутри

Меню на тринадцать пунктов, всё по-русски, всё в консоли:

| | Пункт | Для чего |
|---|---|---|
| 1 | Сведения о системе | ОС, сборка, домен, аптайм, обновления, ожидание перезагрузки |
| 2 | Оборудование | ЦП, память по слотам, диски (SSD/HDD, SMART), видео, сеть, TPM |
| 3 | Драйверы | устройства с ошибками, сторонние и неподписанные, выгрузка в CSV |
| 4 | Сканирование сети | живые узлы подсети, их имена, MAC и открытые порты |
| 5 | DNS | настройки, проверка серверов, разрешение имён, контроллеры домена |
| 6 | Сетевая диагностика | пинг и трассировка без прав админа, проверка порта, выход в интернет |
| 7 | Принтеры | состояние, очередь, пробная страница, лечение зависшей печати |
| 8 | Общие папки | список ресурсов и прав, создание и удаление шары |
| 9 | Открытые файлы и сессии | кто держит файл по сети, закрыть файл или сессию |
| 10 | Права доступа (ACL) | владелец, наследование, выдать/снять права, откат через SDDL |
| 11 | The Bat! → Outlook | перенос писем (.eml/.mbox) и адресной книги в Outlook |
| 12 | Отчёт | сводка по всей машине в TXT и HTML одной командой |
| 13 | Журнал | что программа делала — всё пишется в `tool.log` рядом с exe |

Каждое опасное действие спрашивает подтверждение, а перед изменением прав
или реестра старое состояние уходит в лог — чтобы было куда откатиться.

## Запуск

Скачайте [`multitool.exe`](multitool.exe), запустите — программа сама
попросит права администратора (без них часть пунктов работает в урезанном
виде). Рядом появится `tool.log`.

Технически: один статический бинарник amd64, собран под Go 1.20 (последняя
ветка с поддержкой «семёрки»). Цель — Windows 7, 8, 8.1, 10, 11.

## Подпись и проверка

Файл подписан самоподписанным сертификатом (`multitool-codesign.crt`).
Windows и SmartScreen честно скажут, что издатель им незнаком — это
нормально для сборки «из гаража». Хотите убрать предупреждение — поставьте
сертификат в доверенные (от администратора):

```powershell
Import-Certificate -FilePath multitool-codesign.crt -CertStoreLocation Cert:\LocalMachine\Root
Import-Certificate -FilePath multitool-codesign.crt -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
```

Перед запуском на боевой машине сверьте контрольную сумму с
[`SHA256SUMS.txt`](SHA256SUMS.txt):

```powershell
Get-FileHash multitool.exe -Algorithm SHA256
```

## Пара честных слов

Инструмент делает реальные вещи с системой — меняет права, перезапускает
службу печати, закрывает чужие сессии. Пользуйтесь головой и только на своих
машинах. Автор отвечает за то, что код делает ровно то, что написано, но не
за то, что вы с ним натворите.

Нашли, что сломалось или ведёт себя странно, — заводите issue, посмотрю.
